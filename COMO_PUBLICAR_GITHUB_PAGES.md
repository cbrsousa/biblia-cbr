# 📖 BibliaAI Studio CBR - Progressive Web App (PWA)

Aplicativo Bíblico Inteligente da **Comunidade Batista da Restauração (CBR)** projetado para rodar em:
- 📱 **Celulares Android**
- 🍏 **iPhones (iOS)**
- 💻 **Computadores (Windows / Mac)**

---

## 🚀 Como Publicar 100% Grátis no GitHub Pages:

1. Acesse o seu GitHub: [https://github.com](https://github.com)
2. Crie um novo repositório público (exemplo: `biblia-cbr` ou `biblia-ai`).
3. Faça o upload de **TODOS os arquivos e pastas** desta pasta:
   - `index.html`
   - `styles.css`
   - `app.js`
   - `manifest.json`
   - `sw.js`
   - `favicon.ico`
   - pasta `icons/` (com `icon-192.png` e `icon-512.png`)
4. Vá em **Settings (Configurações do Repositório)** > **Pages** (no menu lateral esquerdo).
5. Em **Branch**, selecione `main` (ou `master`) e clique em **Save**.
6. Aguarde 1 minuto: o GitHub fornecerá o link oficial do aplicativo:
   👉 `https://seu-usuario.github.io/biblia-cbr/`

---

## 📱 Como os Irmãos da Igreja Instalam no Celular:

* **No Android (Google Chrome):**
  1. Abre o link no navegador.
  2. Clica no aviso que surge na parte inferior: **"Adicionar à tela inicial"** (ou nos 3 pontinhos > *Instalar Aplicativo*).
  3. O ícone da Cruz Dourada é criado na tela do celular e abre como um aplicativo nativo.

* **No iPhone (Safari):**
  1. Abre o link no Safari.
  2. Toca no botão de **Compartilhar** (quadrado com seta para cima).
  3. Rola para baixo e toca em **"Adicionar à Tela de Início"**.
  4. Pronto! O app fica fixado na tela do iPhone.
